## คำอธิบายโครงการ

เกม **"กล่องข้าวน้อย (A Mother's Walk)"** เป็นเกม 2D Platformer ที่ตีความนิทานพื้นบ้านไทยใหม่ในมุมของมารดา  
ผู้เล่นเป็นแม่ของไอ้ทอง เดินทางนำกล่องข้าวไปส่งลูก ต้องหลบศัตรู กับดัก และเก็บกระติ๊บข้าวผ่าน 4 ด่าน
