# A Mother's Walk (กล่องข้าวน้อย) — itch.io upload pack

## How to publish on itch.io

1. Go to https://itch.io/game/new and sign in
2. Title: `A Mother's Walk` / `กล่องข้าวน้อย`
3. **Kind of project:** HTML
4. Upload a ZIP of the `html5/` folder in this pack (all files inside, with `index.html` at zip root)
5. Paste description from `ITCH_DESCRIPTION.md`
6. Cover image: use `cover.png`
7. Set visibility to Public (or Restricted for grading)
8. Copy the game URL and put it in the project README

## Controls

- A/D — move
- Space — jump
- J — throw stone
